# Raccoono — Shopify OS 2.0 theme

Raccoono is an original, playful Shopify theme built for visually expressive product brands. It uses native Liquid, CSS and JavaScript with no external storefront dependencies.

## Included

- Configurable announcement bar, header and immersive hero
- Trust features, featured products, brand mission and story
- Accessible personality slider, testimonials, collection cards and comparison table
- UGC gallery, FAQ, newsletter and responsive footer
- Ajax quick add and accessible cart drawer
- Product, collection, cart, page, search and 404 templates
- French and English storefront translations

## Local preview

Install the latest Shopify CLI, authenticate when prompted, then run:

```bash
npm install -g @shopify/cli@latest
shopify theme dev --store your-store.myshopify.com
```

Run the theme validator before deployment:

```bash
shopify theme check
```

Create an unpublished theme:

```bash
shopify theme push --unpublished --store your-store.myshopify.com
```

Replace all temporary editorial copy, choose the menus and collections, and upload brand imagery in the Shopify theme editor before publishing.
